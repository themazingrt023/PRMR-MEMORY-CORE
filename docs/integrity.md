# Integrity

`integrity sweep --mode release-smoke` runs a bounded synthetic lifecycle through authoritative services. `sampled` and `full-scope` use the same content-safe orchestration with separate synthetic scopes. Categories cover sources, candidates, admissions, ledger, temporal dynamics, entities, relationships, query, consolidation, interpretation, canonical signals, governance, jobs, and V1/V2 packets.

Reports contain statuses, hashes, counts, and safe error codes, not source content or evidence text.
