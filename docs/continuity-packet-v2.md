# Epistemic Continuity Packet V2

V2 is an explicit stable-internal packet. It separates asserted, derived, tentative, unknown, and conflicted information; preserves bitemporal and temporal context; includes entities, relationships, lineage, canonical signals, provenance, and governance limitations; and does not let inference replace asserted state.

V2 is deterministic from scoped stored evidence and does not depend on an LLM. Exact consolidation acceleration is accepted only when equivalent to full-ledger output. This implementation is not a claim of scientific validation.
