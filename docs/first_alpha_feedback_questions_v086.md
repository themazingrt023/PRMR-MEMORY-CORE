# V0.86 First Alpha Feedback Questions

Use these questions after the first external controlled alpha tester completes or attempts the flow.

## Understanding

1. Did you understand what PRMR Memory Core does?
2. Did the continuity concept feel different from summaries, logs, or vector search?
3. Could you explain the problem PRMR solves in your own words?

## Setup

4. Was the API setup clear?
5. Were the required headers understandable?
6. Were `client_id`, `vault_id`, and `namespace` understandable?
7. Was the no-sensitive-data rule clear?

## API Flow

8. Did event ingestion make sense?
9. Did the continuity packet idea make sense?
10. Did reconstruction feel useful?
11. Did explanations feel clear and public-safe?
12. Did least-harm action output feel appropriately limited?

## Dashboard And Reports

13. Did dashboard access feel useful?
14. Did the dashboard show the right level of information?
15. Did report access feel safe and understandable?
16. Did reporting feel useful and public-safe?
17. Were usage and request logs useful?

## Confusion And Friction

18. Where did you get confused?
19. What took longer than expected?
20. Which term or concept needs clearer wording?
21. What part of the onboarding pack should be improved first?

## Use Case And Value

22. What use case felt strongest?
23. What use case felt weakest or unclear?
24. Would you want to test this again with more synthetic data?
25. What would make PRMR valuable enough to pilot?

## Trust And Safety

26. What trust or security concerns remain?
27. Did the boundaries feel clear enough?
28. What would you need before using any real approved data?
29. What should be improved before the next tester?
30. What should be improved before next tester selection begins?

## Final Status

31. Which honest result status fits this test?

- `completed_positive`
- `completed_mixed`
- `completed_needs_work`
- `not_completed`
- `revoked`

32. Any final notes?
