# Known Limitations

- Private engineering release candidate, not a public-product or production certification.
- Python 3.11 Windows is the primary locally validated combination; Python 3.12 and Linux need CI evidence.
- SQLite is single-node and one-worker.
- PostgreSQL mode is single-node application operation; no automatic failover or multi-region claim.
- PostgreSQL logical backup depends on external client tooling.
- No external scientific validation, legal certification, compliance certification, or external security assessment.
- Recorded or disabled interpretation is the safe default; model proposals are not truth.
